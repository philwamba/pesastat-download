# Pesa Stat for Android

Analyze your M-Pesa SMS history and create statement-style summaries by person. Data stays on your phone.

## Download

**Current version: 1.0.1 (build 2) · Early Access**

**[Download Pesa Stat for Android](https://github.com/philwamba/pesastat-download/releases/download/v1.0.1-build.2/pesastat-v1.0.1-build.2.apk)**

[Release notes and all versions](https://github.com/philwamba/pesastat-download/releases)

Requires **Android 8.0 or later**. Download and open the APK on your Android device, then allow installation from your browser when prompted.

**Upgrading from the old repository APK:** Version 1.0.1 uses a new signing key, so you must uninstall the old app first. Export any needed reports beforehand: uninstalling deletes local app data. After installing, scan your SMS history again. Future releases will support updating this version in place.

This is an early-access release. Device installation and end-to-end SMS/PDF flows have not been validated for this release.
